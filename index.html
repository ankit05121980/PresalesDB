Proposal Builder App

A Power Apps model-driven application that streamlines the presales process, from proposal management to project estimation. Sales teams, presales consultants and project managers can create, track and refine proposals together.

Key features

Proposal management dashboard

All active proposals in one view, with status tracking and visual funnels.

Guided proposal creation

Step-by-step workflows that keep proposals consistent and professional.

Estimation management

Pre-built templates for accurate project estimates that you can adapt to your workflows.

Version control

Clone and refine estimations as requirements change.

Advanced reporting

Dashboards for progress, milestones and success metrics.

Collaboration

Works with Dynamics 365 Sales to give one connected presales experience.

Getting started

  1. Download the managed solution file below.
  2. Open the Power Apps Maker Portal, go to Solutions → Import Solution, and select the .zip file.
  3. Click Publish All Customizations when the import is complete.
  4. Assign the Proposal Builder User security role and configure workflows and estimation templates.
  5. Optionally, import the sample data (Technologies → Phases → Sub Phases → Estimation Factors → Estimations → Estimation Details).
