Getting started

  1. Download the managed solution .zip.
  2. In the Power Apps Maker Portal, go to Solutions → Import Solution and select the file.
  3. Confirm the solution is Proposal Builder (managed), import it, then Publish All Customizations.
  4. Assign security roles and configure estimation templates for your business.
  5. Optionally import the sample data (Technologies → Phases → Sub Phases → Estimation Factors → Estimations → Estimation Details).
